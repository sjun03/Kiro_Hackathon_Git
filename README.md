# 게임 여가 추천기 (가칭: PlayPick)

> "지금 2시간 비었어" 라고 입력하면, 내 게임 라이브러리 상태와 가용 시간을 보고
> **지금 하기 딱 좋은 게임과 플레이 분량을 AI가 추천**해주는 사이트

Kiro Hackathon 프로젝트 계획서

---

## 1. 한 줄 소개

내 게임 목록(진행도·플레이 상태 포함)과 지금 비어 있는 시간을 입력하면,
AI가 **"무슨 게임을 몇 시간 하면 좋은지"** 를 이유와 함께 추천해준다.

## 2. 해결하려는 문제

게이머들이 겪는 흔한 고민:

- "2시간 비었는데 뭐 하지?" 하다가 게임 고르는 데 시간을 날린다
- 안 끝낸 게임이 쌓여 있는데 자꾸 새 게임만 산다
- 짧게 비었는데 긴 RPG를 켜서 애매하게 끝낸다

→ **"가용 시간"과 "게임 상태"를 매칭**해 최적의 선택을 대신 골라준다.

## 3. 핵심 가치 / 차별점

- 단순 취미 추천이 아니라 **내 라이브러리 + 남은 시간**을 종합해 추천
- 추천뿐 아니라 **"지금은 이 게임 하지 마"** 같은 비추천도 제시
- "안 산 게임 / 샀는데 안 함 / 하는 중 / 깸" 상태를 반영

## 4. 데이터 모델

### 게임(Game)

| 항목 | 예시 | 추천에 쓰이는 이유 |
|------|------|------|
| 제목 | 엘든링 | 식별 |
| 상태 | 안 삼 / 샀는데 안 함 / 하는 중 / 깸 | 추천/구매 제안 판단 |
| 진행도 | 60% | 이어서 할지 결정 |
| 장르 | 액션RPG | 취향 매칭 |
| 1회 세션 적정 시간 | 짧음 / 보통 / 긴 편 | 가용 시간과 매칭 ⭐ |
| 저장 편의성 | 아무때나 종료 / 체크포인트만 | 짧은 시간 적합도 ⭐ |
| 선호도 | 좋아함 / 보통 | 기분 반영 |

### 추천 요청(사용자 입력)

| 항목 | 예시 |
|------|------|
| 가용 시간 | 2시간 |
| 시간대 / 상황 | 늦은 밤, 피곤함 |
| 기분 | 가볍게 / 몰입하고 싶음 |

### AI 응답 형태(예시)

```json
{
  "recommendations": [
    {
      "game": "하데스",
      "playTime": "1시간 30분",
      "reason": "한 판이 짧아 2시간 안에 깔끔하게 즐기기 좋고, 밤에 가볍게 하기 적합해요.",
      "action": "이어서 하기 (진행도 45%)"
    },
    {
      "game": "엘든링",
      "playTime": "비추천",
      "reason": "몰입형이라 2시간은 애매해요. 주말 긴 시간에 추천."
    }
  ]
}
```

## 5. 화면 구성 (MVP)

1. **내 게임 라이브러리** — 게임 추가/수정 (상태·진행도·장르·세션 길이 입력)
2. **"지금 쉴래" 입력** — 가용 시간 + 상황 + 기분 선택
3. **추천 결과** — AI 추천 카드 2~3개 + 이유 + 비추천

## 6. 동작 흐름

```
[게임 라이브러리 입력] ──저장(localStorage)──┐
                                             │
[지금 쉴래: 2시간, 밤, 가볍게] ──────────────┤
                                             ▼
                              [백엔드: 게임목록 + 상황을 프롬프트로 조합]
                                             │
                                             ▼
                                   [AI(Gemini) 호출]
                                             │
                                             ▼
                              [추천 카드 2~3개 + 이유 표시]
```

AI가 삽입되는 지점 = 백엔드가 사용자 데이터를 프롬프트로 만들어 AI API를 호출하는 부분.

### API 키 설정 (.env 한 곳에서 관리)

모든 API 키/시크릿은 **`.env` 파일 한 곳**에서 입력받는다.
`.env.example` 을 복사해 `.env` (또는 `.env.local`)로 만들고 값을 채운다.

```bash
cp .env.example .env   # Windows PowerShell: Copy-Item .env.example .env
```

| 변수 | 용도 | 비우면 |
|------|------|--------|
| `GEMINI_API_KEY` | AI 추천 (Gemini) | mock 추천으로 자동 동작 |
| `STEAM_API_KEY` | Steam 라이브러리 가져오기 (MCP) | Steam 연동 제한 |
| `STEAM_ID` | 17자리 SteamID (MCP) | Steam 연동 제한 |

- `GEMINI_API_KEY` 는 Next.js 서버(`src/lib/recommend.ts`)가 자동으로 읽는다.
  키가 들어오면 mock → 실제 Gemini 호출로 전환된다 (프론트 수정 불필요).
- `STEAM_API_KEY` / `STEAM_ID` 는 MCP 서버가 `dotenvx` 를 통해 같은 `.env` 에서 읽는다.
- `.env*` 파일은 `.gitignore` 에 포함되어 커밋되지 않는다.
- 값을 바꾸면 서버(및 MCP 서버)를 재시작/재연결한다.

## Steam 연동 (MCP로 라이브러리 가져오기)

Steam 보유 게임·플레이타임을 수동 입력 대신 가져오는 방법. **MCP는 앱 사용자 기능이
아니라 개발/데모용 데이터 준비 도구**다. Kiro(또는 다른 MCP 클라이언트)가 Steam MCP
서버로 내 라이브러리를 읽어 PlayPick에 시드 데이터로 넣는 방식.

### 1) MCP 서버 설정

`.kiro/settings/mcp.json` 에 `@praeses/steam-mcp` 서버가 등록돼 있다.
**모든 키는 json이 아니라 `.env` 에서 읽는다.** 서버는 `@dotenvx/dotenvx run` 으로
`.env` 를 로드한 뒤 steam-mcp 를 실행하므로, json 파일에는 시크릿이 들어가지 않는다.
`npx` 로 바로 구동되므로 별도 설치/빌드도 필요 없다.

`.env` (또는 `.env.example` 복사본)에 아래 값을 채운다:

- `STEAM_API_KEY`: https://steamcommunity.com/dev/apikey 에서 본인 Steam 계정으로 무료 발급
- `STEAM_ID`: 17자리 SteamID (프로필에서 확인)

주의:
- 프로필의 "게임 상세정보"가 **공개**여야 플레이타임이 API로 보인다
- `.kiro/settings/mcp.json` 의 `-f` 경로는 이 프로젝트의 `.env` 절대경로로 지정돼 있다.
  프로젝트 위치를 옮기면 그 경로도 함께 수정한다.
- 값을 채운 뒤 Kiro의 MCP Server 뷰에서 steam 서버를 재연결한다.

### 2) 라이브러리 가져오기

1. Kiro에게 "내 Steam 보유 게임 목록 가져와줘" 요청 → steam-mcp가 GetOwnedGames
   형태의 JSON을 반환
2. 그 JSON을 복사해 PlayPick `/library` 화면의 **"Steam에서 가져오기"** 칸에 붙여넣고
   가져오기 클릭
3. `src/lib/steam.ts` 의 `fromSteamOwnedGames()` 가 플레이타임으로 상태·진행도를
   자동 추정해 Game[] 로 변환

### 추정 규칙 (휴리스틱)

Steam은 "깸" 여부나 세션 길이를 알려주지 않으므로 추정한다. 가져온 뒤 라이브러리
화면에서 손쉽게 수정할 수 있다.

| 항목 | 추정 방식 |
|------|-----------|
| 상태 | 총 플레이 < 30분 → "샀는데 안 함" / 최근 2주 0분 & 누적 ≥ 40시간 → "깸" / 그 외 "하는 중" |
| 진행도 | 깸=100, 안함=0, 하는 중=플레이타임 기반 러프 추정(최대 90%) |
| 선호도 | 최근 2주 플레이가 있으면 "좋아함" |
| 세션 길이 | 알 수 없음 → "보통" 기본값 (수동 조정) |
| 장르 | GetOwnedGames엔 없음 → 빈 값 (수동 입력 또는 store API로 보강) |
